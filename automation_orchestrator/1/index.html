Introduction to Automation Orchestrator for Red Hat Ansible Automation Platform

Introduction

In this course, you will learn how the automation orchestrator extends Red Hat Ansible Automation Platform to design, execute, and govern complex, multi-step automation workflows. You will explore core workflow concepts, the visual workflow designer, AI task agents, event-driven triggers, human approval gates, and integration capabilities.

You will also discover how the automation orchestrator unifies existing Ansible automation, AI-driven decision making, external tool integrations, and governance controls to deliver coordinated automation across hybrid IT environments.

Duration: …

Objectives

By the end of this course, you will be able to:

  • Understand automation orchestrator architecture and core concepts.

  • Design multi-step canvas workflows with appropriate steps and data flows.

  • Learn about different Steps settings and what their purpose is.

  • Integrate APIs, event-driven triggers, AI agents, MCPs, and governance controls.

  • Implement an end-to-end workflow for a practical IT use case.

Prerequisites

Before taking this course, you should have: - A working understanding of Red Hat Ansible Automation Platform and its core components - Familiarity with basic Ansible automation concepts and workflows
